Typography

One typeface, a few sizes.

San Francisco on Apple devices, a system sans everywhere else. Tight, slightly negative letter-spacing on anything large; nothing is ever bolder than semibold (600).

Display

56px / 1.07 / weight 600 / -0.005em — hero headlines

Section title

Subhead / lede

24px / 1.38 / weight 400 / secondary colour

Body copy sits at 17px, Apple's base size — noticeably larger than most sites' default 16px, which is part of why the page feels calm rather than dense.

Buttons & links

Pills and chevrons.

Two button weights, both fully rounded (radius 980px reads as "just make it a pill" regardless of height), plus a plain link with a trailing chevron for anything lower-commitment than a button.

Spacing & layout

Room to breathe.

Content sits in a 1024px column. Sections run 96–120px of vertical padding — roughly double what a typical dense app UI would use — and alternate white / #f5f5f7 to separate them without drawing a line.

Components

The app card, restyled.

Same information as the dark App Store cards on this site today — icon, name, status, description — in this lighter language: bigger radius, a hairline border instead of a filled panel, and the status pill tinted instead of solid.
